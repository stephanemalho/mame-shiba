# Agent Entry Point

This repository keeps agent-facing instructions in `docs/`.

Before changing SEO, metadata, sitemap, images, or PageSpeed-related code, read:

- `docs/agents.md`
- `docs/image-performance-rules.md`

These notes are part of the project workflow. They exist to prevent repeated
performance regressions, especially around image preloading and `next/image`
priority usage.
